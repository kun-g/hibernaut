4 条硬门禁（CI 强制拦截架构漂移）
GATE 01 · 零业务反向依赖
.importlinter 禁止 runner 导入 agent_runtime 或 workshop

Runner 只能依赖标准库、JSON Schema 协议与自身驱动；反向导入直接阻断 PR 合入。

GATE 02 · ADR-0001 双向契约测试
Producer 真实产出与 Consumer 夹具同过 Draft 2020-12 校验

v1 只允许新增可选字段，禁止删字段或改类型；破坏性变更强制升 schemas/v2/。

GATE 03 · 命名空间前缀隔离红线
hb-* 与 ws-* 物理目录、分支与回收权严格隔离

回收与写校验必须同时核验 namespace + owner_scope + 本地登记表，绝不跨项目误删。

GATE 04 · 进程内零长期明文密钥
子进程环境统一剥离长效 Token，仅放行 Broker 短期 Lease

沿用现有 child_env() 剥离机制，上 VPS 前所有 GitHub/API 凭据强制走外置 Broker 代理。
